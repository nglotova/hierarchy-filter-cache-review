# dfs-hierarchy-filter

Take-home assessment for Tempo:

1. `hierarchy/`: implementation and tests of `Hierarchy.filter()` for a forest stored as parallel DFS-ordered arrays of node IDs and depths.
2. `code-review/`: review of the `SimpleCache` implementation.

## Running

Requires JDK 21. If it isn't installed, Gradle downloads it automatically.

```bash
./gradlew test
```
